Observability

Home Server Monitor

Monitoring for a repurposed laptop that runs Immich, Builder's Ledger and other apps in Docker 24/7. One event-driven Python process uses about 0.2% CPU and under 100 MB RAM (capped at 150 MB by systemd): link changes, Docker events and mains/battery switches arrive as events, and only the per-line internet check and the heartbeat run on timers. It tracks two internet lines with failover, power and battery, smart-plug energy and cost, containers, apps, and HDD health via SMART, in SQLite with hourly rollups kept permanently. No open ports: the FastAPI dashboard listens on localhost and is reached through Cloudflare Tunnel behind Cloudflare Access, or Tailscale. A Cloudflare Worker emails when heartbeats stop, and events queued during an outage arrive with the first heartbeat afterwards, so the "back online" email can say what happened.
